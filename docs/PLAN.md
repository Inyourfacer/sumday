# Sumday — Build Plan

Each phase ends with something usable. See [DESIGN.md](DESIGN.md) for the details.

## Phase 0: Foundations
- Scaffold TypeScript + React + Vite UI, a Fastify server and SQLite
  (better-sqlite3) with a migration runner.
- Vitest, oxlint and typecheck. GitHub Actions run lint, test and build on
  every push.
- Money (integer cents) and date utilities, with tests.
- `npm start` serves the UI and API on `localhost`.

**Done when:** `npm start` opens an empty Sumday dashboard and CI is green.

## Phase 1: Accounts + import
- First-run setup wizard and the Settings → Household page: people, household,
  employer plans with match tiers, pensions and Social Security estimates.
- Accounts (all types, owners, tax treatment).
- Manual transactions and balance snapshots.
- Import pipeline: format detection, generic CSV with a column-mapping screen
  saved per account, OFX/QFX, dedupe, a staging review screen, and undo for
  whole batches.
- Categories, payee normalization, rules, learning from corrections, and the
  Uncategorized inbox.
- Transfer pair detection.

**Done when:** a few months of real transactions from your accounts are
imported, categorized and deduplicated.

## Phase 2: Spending, budget, net worth
- Fixed / Flex / Non-monthly budgets, with sinking funds for non-monthly items.
- Monthly budget view, trends, cash flow and savings rate.
- Recurring detection and the bills calendar.
- Net worth history.

**Done when:** you can run a month on the Flex budget and see net worth.

## Phase 3: Goals, debt, waterfall
- Goals with earmarking, required monthly amounts and status; the emergency
  fund goal.
- Debt payoff engine (avalanche/snowball, schedule, comparison).
- Yearly limits data file and year-to-date contribution tracking.
- Waterfall engine with editable steps, and the **Next best moves** list with
  "why" and "numbers behind it".

**Done when:** the dashboard tells you where this month's surplus should go,
and why.

## Phase 4: Investments
- Holdings import (positions + cost basis lots), securities with asset-class
  mixes and expense ratios.
- `PriceProvider` interface, the Tiingo provider (free key in `.env`), proxy
  tickers for funds with no ticker, manual prices, and a daily price job with
  backfill.
- Allocation (household/account/person), target and drift band, rebalancing
  suggestions, asset location hints, fee drag and XIRR.

**Done when:** you see your real allocation vs target and what to buy with the
next contribution.

## Phase 5: Retirement
- Bundled historical returns dataset (with source/licence note).
- Monte Carlo engine: block bootstrap, seeded RNG, tax buckets, contributions,
  Social Security, pensions, RMDs, withdrawal order, flat-rate `TaxModel`.
- Retirement spending built from the actual budget, with adjustments and
  one-off expenses.
- Outputs: success probability, percentile bands, sustainable spending, the
  "retire at X?" table, and the "smallest change to get on track"
  recommendation.

**Done when:** you get a success probability you trust, and you can trace how
it was calculated.

## Phase 6: Scenarios, alerts, monthly report
- Scenarios with overrides, side-by-side comparison of up to 3, and promoting
  one to the base plan.
- Alert engine with editable thresholds; dashboard alerts and desktop
  notifications.
- Monthly review report (HTML, printable), generated by the scheduler on the
  1st.
- Daily backups and CSV/JSON export.

**Done when:** Sumday runs itself month to month and you only review it.

## Later
- Automated import pipeline (watched folder or email inbox → the same staging
  review).
- Institution-specific adapters (paused).
- Bracket-based `TaxModel`, Roth conversion planning and tax-optimized
  withdrawal order.
- Parametric returns as an alternative Monte Carlo mode.
